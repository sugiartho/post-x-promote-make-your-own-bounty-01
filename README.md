Promote make.fun's make-your-own-bounty post on X. The entry is a public
post from @markmarsen quoting make.fun's post, with a photo of its own
attached, the line "Make your own bounty on @makefunai:
https://make.fun/sponsor/new" and the entrant's play code in its text.
`POST.json` names the post's address; `main.ts` copies it to `/output`
for the gate to read.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
